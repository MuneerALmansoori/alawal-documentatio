# مركز توثيق الأول

موقع توثيق عربي مبني باستخدام VitePress وقالب Vue مخصص يحافظ على الهوية البصرية لثيم الأول.

## التشغيل المحلي

```powershell
pnpm install
pnpm docs:dev
```

يفتح خادم التطوير عادة على `http://localhost:5173`.

## إدارة المحتوى

يشمل المشروع لوحة إدارة مبنية باستخدام Decap CMS. لتشغيل موقع التوثيق ووكيل الحفظ المحلي معاً:

```powershell
pnpm docs:admin
```

ثم افتح:

- موقع التوثيق: `http://localhost:5173/`
- إدارة المحتوى: `http://localhost:5173/admin/index.html`

في التشغيل المحلي يتصل Decap CMS بالوكيل المحلي على المنفذ `8081` ويحفظ التعديلات مباشرة في ملفات Markdown. عند نشر لوحة الإدارة يلزم إعداد مصادقة GitHub من خلال Decap Turbo أو مزود OAuth متوافق.

## البناء والمعاينة

```powershell
pnpm docs:build
pnpm docs:preview
```

يُحفظ البناء النهائي داخل `.vitepress/dist`.

## النشر على GitHub Pages

ينشر مسار GitHub Actions الموجود في `.github/workflows/deploy-pages.yml` الموقع تلقائياً عند الدفع إلى فرع `master`.

رابط الموقع:

`https://muneeralmansoori.github.io/alawal-documentatio/`

بعد أول رفع افتح إعدادات المستودع، ثم **Pages**، واختر **GitHub Actions** من قائمة **Source** إذا لم تكن محددة تلقائياً.

## بنية المشروع

- `.vitepress/config.mjs`: إعداد VitePress والبحث المحلي وبيانات الموقع.
- `.vitepress/theme/Layout.vue`: القالب العربي المخصص والتفاعلات.
- `.vitepress/theme/custom.css`: التصميم المتجاوب والوضع الليلي.
- `.vitepress/theme/site-data.js`: القائمة الجانبية والاختصارات ومسارات الصفحات.
- `public/admin`: صفحة إدارة المحتوى وإعداد مجموعات Decap CMS.
- `public/assets`: الصور والأصول العامة.
- ملفات `*.md`: محتوى صفحات التوثيق، وكل ملف يمثل مساراً مستقلاً.

## إضافة قسم وصفحات من لوحة الإدارة

1. افتح **الأقسام والصفحات** في لوحة إدارة المحتوى.
2. أنشئ مدخلاً جديداً للقسم، واكتب مساراً إنجليزياً قصيراً مثل `store-design`؛ سيُحفظ القسم في `content/store-design/index.md`.
3. أنشئ الصفحات التابعة داخل القسم بمسارات مثل `store-design/colors` و`store-design/header`.
4. استخدم اسم القسم نفسه في حقل **اسم القسم في القائمة** لجميع صفحاته.
5. اضبط ترتيب القسم والصفحات بالأرقام، ثم احفظ وانشر.

تُضاف الأقسام والصفحات الجديدة تلقائياً إلى القائمة الجانبية والبحث عند إعادة بناء الموقع، ولا تحتاج إلى تعديل `site-data.js`.

## إضافة صفحة يدوياً

أنشئ ملف Markdown في القسم المناسب، ثم أضف `title` و`description` و`section` و`icon` في Frontmatter. الصفحات اليدوية القديمة تظل معرفة في `site-data.js`، أما الصفحات المنشأة من لوحة الإدارة فتُكتشف تلقائياً من مجلد `content`.

مثال:

```md
---
title: "عنوان الصفحة"
description: "وصف قصير يظهر أعلى الشرح وفي نتائج البحث."
section: "تخصيص التصميم"
icon: "palette"
---

محتوى الشرح هنا.
```
